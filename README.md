# 🏦 Loan Approval Prediction

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![FinTech](https://img.shields.io/badge/FinTech-Classification-green.svg)

## 📖 Overview

Binary classification model to predict loan approval decisions based on applicant information including income, credit history, employment, and loan amount. Automates lending decisions.

## 🎯 Features

- Loan approval prediction
- Credit risk assessment
- Applicant profiling
- Decision automation

## 🛠️ Tech Stack

- Scikit-learn, XGBoost
- Pandas, NumPy
- Matplotlib, Seaborn

## 🚀 Quick Start

```bash
git clone https://github.com/adityavdn/Loan-Approval-Prediction.git
pip install -r requirements.txt
jupyter notebook
```

## 📊 Key Factors

- Credit History
- Income, Co-applicant Income
- Loan Amount, Term
- Property Area, Education
